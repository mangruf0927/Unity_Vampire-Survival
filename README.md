# ⚔️ 3D Vampire-Survival

Unity를 활용해 개발한 **3D 자동 공격 서바이벌 게임**입니다.

끊임없이 몰려오는 적을 처치해 경험치를 획득하고 무기와 장신구를 강화하며 **10분 동안 생존하는 것**을 목표로 합니다.

**ChatGPT와 Codex를 활용해 게임 기획, 기능 구현 및 문제 해결**을 진행했습니다. AI가 제안한 구현 방식을 직접 검토하고 **Unity 플레이 테스트와 성능 측정을 통해 기능을 검증하고 개선**하며 게임의 완성도를 높였습니다.

## 💻 핵심 구현

### 1. 자동 공격 및 성장 시스템

자동 공격으로 적을 처치하고, 경험치와 레벨업을 통해 무기와 장신구를 강화하는 전투 시스템을 구현했습니다.

- 마법 지팡이, 단검, 성경, 채찍 **자동 공격 무기 4종**
- 캐릭터별 시작 무기와 고유 능력 적용
- 경험치 획득 및 레벨업 선택 시스템
- JSON 기반 무기 및 장신구 능력치 및 강화 데이터 관리
- 무기별 공격 방식과 명중 판정 구현

### 2. 다수의 적 이동 및 충돌 처리 개선

적 간 충돌 처리 방식을 결정할 때 **Collider 방식을 제안했지만 Codex는 성능을 고려해 Grid 방식을 추천**했습니다.
Grid를 적용한 뒤 적이 1,000마리를 넘어가자 렉이 발생했고 Unity Profiler에서 적 간 충돌 처리에 많은 시간이 소요되는 것을 확인했습니다.
Codex에 별도 테스트 씬에서 두 방식의 성능을 비교하도록 요청했습니다. 테스트 조건과 Collider 반경별 적 배치 상태를 직접 검토한 뒤 결과를 바탕으로 이동 구조를 변경했습니다.

**평균 프레임 시간 비교**

| 적 수 | Grid | Collider |
|---|---:|---:|
| 500마리 | 16.236ms | 8.061ms |
| 1,000마리 | 87.151ms | 9.687ms |

측정 결과 Collider 방식의 평균 프레임 시간이 더 낮게 나타나 일반 적의 이동과 충돌 처리를 **Rigidbody, Collider 기반으로 변경**했습니다.
기존 Grid는 무기 명중 후보 검색 등에 활용하도록 유지했습니다.

*※ 별도 테스트 씬에서 측정한 결과이며, 충돌 반경 등 일부 조건이 다릅니다.*

### 3. 이벤트 적의 대형 이동 시스템

이벤트 박쥐에도 Rigidbody 이동을 적용한 뒤 대형이 흐트러지는 문제가 발생했습니다. Codex와 충돌 및 대형 복귀 문제를 함께 수정했지만 이후 무리 전체가 멈추는 현상까지 나타났습니다.

추가 수정을 중단하고 **이전 Git 코드와 현재 구현을 비교하도록 요청**했습니다. 이후 일반 적의 Rigidbody 이동은 유지하고 이벤트 적만 기존 위치 기반 이동으로 복구했습니다.

- 일반 적: Rigidbody 기반 이동
- 이벤트 적: 시간 기반 경로 이동
- 이벤트 전용 이동 컴포넌트와 프리팹 분리
- 공통 ObjectPool에서 일반 적과 이벤트 적을 별도 풀 종류로 관리

현재는 해당 이동 구조를 이벤트 슬라임에 적용하고 있습니다.

### 4. JSON 기반 스테이지 데이터 관리

스테이지 진행 시간, 일반 적 생성 정보, 이벤트 적 설정이 코드와 씬, JSON에 분산되어 있었습니다.

Codex가 제안한 데이터 통합 방안을 검토하고 **기존 설정값과 동작을 유지하면서 스테이지 관련 데이터를 `Stage.json`으로 통합**했습니다.

이를 통해 스테이지 설정을 한곳에서 관리할 수 있도록 구조를 개선했습니다.

### 5. 맵 청크 및 오브젝트 재사용

플레이어 이동에 따라 숲 맵 청크를 배치하고, 사용하지 않는 청크를 재사용하도록 구현했습니다.

- 플레이어 위치에 따른 맵 청크 관리 및 재사용
- 적, 경험치 보석, 맵 청크, 일부 아이템에 오브젝트 풀링 적용
- 재사용 오브젝트의 활성화 및 초기화 처리

## 🤖 AI 협업 및 개발 과정

반복되는 작업 지침은 `AGENTS.md`에 정리하고, 게임 기획과 구현 명세는 `CONTENTS.md`에서 별도로 관리했습니다.
