# 3D 생존 게임 기준 기획서

- 작성일: 2026-11-04
- 목적: 기능을 하나씩 구현할 때 참고하는 프로젝트의 기준 기획서
- 참고 게임: [Vampire Survivors](https://namu.wiki/w/Vampire%20Survivors)
- 문서 상태: 사용자가 확정한 요구사항과 검토 과정에서 나온 제안·미결정 사항을 구분한다.

## 1. 문서 사용 원칙

- 전체 목표를 기록한 문서이며, 모든 기능을 한 번에 구현하라는 의미가 아니다.
- 앞으로 사용자가 요청하는 기능만 하나씩 구현한다.
- 아래의 **확정 기획**은 구현 기준으로 사용한다.
- **권장안**은 제안이며 사용자 승인 없이 확정 요구사항으로 취급하지 않는다.
- **미결정 사항**은 해당 기능 구현 전에 확인한다. 특히 장신구의 애매한 적용 방식을 임의로 결정하지 않는다.
- 새롭게 합의한 내용은 이 문서에 반영하여 기준을 유지한다.
- 참고 게임과 설명이 다른 경우, 사용자가 명시한 이 프로젝트의 규칙을 우선한다.
- 참고 링크는 초기 검토 당시 직접 열리지 않았으므로, 이 문서는 사용자가 제공한 설명을 기준으로 작성했다.

## 2. 게임 개요 — 확정 기획

| 항목 | 내용 |
| --- | --- |
| 장르 | 3D 뱀파이어 서바이벌 스타일 생존 게임 |
| 최종 목표 | 약 10분 동안 플레이할 수 있는 프로토타입 완성 |
| 승리 조건 | 10분 동안 생존 |
| 패배 조건 | 플레이어 현재 체력이 0 이하 |
| 조작의 중심 | 이동과 레벨업 선택 |
| 공격 | 별도 공격 키 없는 자동 공격 |
| 일반 적 | 박쥐, 좀비, 스켈레톤, 유령, 머드맨의 5종 |
| 보스 | 등장하지 않음 |
| 초기 제외 범위 | 장신구 해금 조건, 무기 진화 시스템 |

### 핵심 진행 흐름

플레이어 이동 → 적 생성 및 추적 → 플레이어 자동 공격 → 적 처치 → 경험치 획득 → 레벨업 → 무기 또는 장신구 획득·강화 → 생존

## 3. 플레이어 — 확정 기획

- WASD 또는 방향키로 이동한다.
- 기본 최대 체력과 시작 체력은 100이다.
- 현재 체력이 0 이하가 되면 게임이 종료된다.
- 공격 키를 누르지 않아도 보유 무기가 자동으로 공격한다.

### 확정된 이동 규칙

- 월드 기준으로 이동한다. W·↑는 +Z, S·↓는 -Z, D·→는 +X, A·←는 -X이다.
- XZ 평면에서 이동하며 Y 좌표를 유지한다.
- 대각선 이동을 지원하며 상하좌우 이동과 속도가 같다.
- 이동 방향을 바라보고, 멈추면 마지막으로 바라보던 방향을 유지한다.
- 초기 이동 속도는 초당 5이며 인스펙터에서 수정할 수 있다.
- 입력은 PlayerInput의 Send Messages와 `OnMove(InputValue value)`로 받는다. 기존 Input Actions 에셋의 이동 전용 `Movement/Move`를 사용한다.
- CharacterController.Move로 수평 이동한다. 중력은 적용하지 않으며, 현재 평면 스테이지의 계단·경사 오르기 설정은 0이다.
- Player는 Player 레이어(8), 바닥은 Ground 레이어(9)를 사용하며 Physics 충돌 매트릭스에서 두 레이어 사이의 충돌만 제외한다. 바닥 접촉 보정으로 시작 높이가 상승하는 것을 방지한다.
- 평면 스테이지에서 Player 시작 Y는 1, 바닥 표면 Y는 0, 컨트롤러 Height는 2, Center는 0, Skin Width는 0.08로 유지한다. 바닥은 물리적으로 플레이어를 지지하지 않으며, 향후 벽·장애물은 Ground 외의 충돌 가능한 레이어를 사용한다.
- 이동 방향으로 즉시 움직이되 회전은 초당 720도의 기본 속도로 부드럽게 처리한다. 회전 속도는 인스펙터에서 수정할 수 있다.
- 입력을 놓으면 그 순간의 위치와 회전 방향을 유지한다.
- 경사면이나 다른 Collider와의 겹침 해소에 의한 Y 변화까지 강제로 잠그는 구조는 아니다. 높이 지형을 도입할 때 이동 규칙을 재검토한다.

### 확정된 플레이어 체력·접촉 피해 규칙

- PlayerHealth의 기본 Max Health는 100이며 인스펙터에서 조절한다. 시작 체력은 최대 체력과 같다.
- EnemyMovement의 기본 Damage는 정수 10이며 적 프리팹에서 조절한다. PlayerHealth의 Damage Interval 기본값은 1초이며 Player 인스펙터에서 조절한다. 접촉 피해용 별도 컴포넌트는 사용하지 않는다.
- 플레이어 공통 피해 간격을 사용한다. 피해를 받은 뒤 PlayerHealth의 Damage Interval 동안 다른 적의 피해도 받지 않는다. 여러 적이 동시에 닿으면 먼저 처리된 유효 접촉 하나만 피해를 적용한다.
- 군중 이동 후 XZ 중심 거리와 기존 Body Radius + Player Radius로 접촉을 검사한다. 이동의 정지 오차를 고려해 0.002의 허용 오차를 포함한다. 물리 Collider나 밀어내기는 추가하지 않는다.
- IDamageable은 `TakeDamage(int damage)`만 정의한다. PlayerHealth와 EnemyHealth가 구현하고, EnemyMovement와 MagicProjectile은 인터페이스로만 피해를 전달한다. 기존 피해량 10과 체력 설정은 유지한다.
- 체력은 0 아래로 내려가지 않는다. 체력 0이면 사망 상태를 기록하고 Time.timeScale을 0으로 설정해 게임 진행을 멈춘다. Console에 Game Over를 출력한다. 씬 종료 시 사망으로 정지시킨 시간을 복원한다.
- 체력 UI, 결과 UI, 재시작, 회복, 플레이어 공격 피격 효과는 이번 구현 범위에 포함하지 않는다.

### 확정된 카메라 규칙

- 직교(Orthographic) 투영의 월드 Z축 기준 쿼터뷰를 사용한다. 대각선 구도 대신 이 구도로 최종 확정했다.
- 기본 고정 회전은 X=45도, Y=0도, Z=0도이다. 플레이어가 회전해도 카메라 각도는 바뀌지 않는다.
- CameraFollow가 LateUpdate에서 플레이어의 추적 위치로 즉시 이동한다. 플레이어가 이동하면 카메라도 즉시 이동하고, 멈추면 즉시 멈춘다. 추적 보간이나 지연은 사용하지 않는다.
- 시작 시에는 추적 위치에 즉시 배치해 진입 이동을 없앤다.
- 기본 Orthographic Size는 8, 추적 거리는 20이다. 인스펙터에서 구도를 조절할 수 있다.
- 직교 투영의 화면 범위는 Camera의 Size로 조절한다. Distance는 배치 거리이며 확대·축소 값이 아니다.
- 기존 월드 기준 이동을 유지하며 W·↑는 화면 위쪽, D·→는 화면 오른쪽으로 이동한다.
- 이번 범위는 고정 구도와 즉시 추적까지이다.

## 4. 적 — 확정 기획

- 플레이어의 화면 밖에서 생성된다.
- 생성된 적은 플레이어를 추적한다.
- 각 적은 체력을 가지며 체력이 0 이하가 되면 사망한다.
- 처치 시 일정 확률로 경험치 보석을 생성한다.
- 진행 시간에 따라 등장하는 종류와 생성량이 달라진다.
- 일반 적은 5종이며 보스는 없다.
- 박쥐 무리는 별도 적 종류가 아니라 기존 박쥐를 짧은 시간 동안 대량 생성하는 이벤트이다.

### 박쥐 이동 — 현재 구현 규칙

- 되돌린 군중 이동 알고리즘을 유지하고 역할만 EnemyMovement와 EnemyCrowd로 분리한다.
- EnemyMovement는 기존 인스펙터 설정, 개별 적 상태, 이동·접근 정지·회전을 담당한다.
- EnemyCrowd는 활성 적 등록, 격자 구성·검색, 이웃 분리·겹침 계산, 전체 시뮬레이션 순서를 담당하는 정적 클래스이다. 별도 컴포넌트를 추가하지 않는다.
- 플레이어 Transform을 인스펙터에 지정한다. XZ 평면에서 추적·좌우 회피·분리 이동·겹침 보정을 수행하며 각 적의 Y는 유지한다.
- 이동 방향과 관계없이 플레이어를 향해 회전한다.
- 코드 기본 이동 속도는 3, 회전 속도는 360도/초이다. GameScene의 기존 설정은 이동 속도 3, 회전 속도 540도/초로 유지한다.
- 적의 자발적인 접근 정지 거리는 Body Radius + Player Radius로 계산한다. GameScene에서는 0.5 + 0.4 = 0.9이다. Player Radius는 실제 Player Collider와 자동 연결되지 않는 이동용 설정값이다.
- 플레이어는 적에게 막히거나 적을 밀지 않고 통과한다. 플레이어 반경 안의 적을 바깥으로 강제 배치하던 LimitApproach는 제거했다. 접근 정지는 추적 속도에만 반영하고, 플레이어와 적의 겹침은 허용한다. 적끼리의 분리와 겹침 보정은 유지한다.
- 접촉 거리까지 남은 간격이 0.001 이하이면 적의 속도와 자발적 이동을 멈춘다. 플레이어가 먼저 겹쳐 들어와도 바깥으로 밀어내지 않는다. 접촉 전에는 속도 보간의 잔여 관성을 포함한 실제 이동량을 남은 간격으로 제한한다. 적끼리 겹침을 해소하기 위한 보정 이동은 계속 허용한다.
- 이전 Separation Distance 0.3은 반경 합에 더하던 여유 거리였다. 현재 Separation Range는 절대 검색 범위이므로 GameScene의 같은 크기 적 기준 1.3으로 이관한다. Separation Strength 1.5는 유지한다.
- Overlap Correction Speed는 3으로 설정한다. 외형·군중 밀도 조정은 이 코드의 인스펙터 설정으로 수행한다.
- 활성화·비활성화 시 적 목록에 등록·해제한다. 추가 관리 오브젝트는 필요 없다.
- LateUpdate에서 한 프레임에 한 번 전체 무리를 계산한다. 큰 프레임 간격은 최대 4개 단계로 나누고 각 단계에서 겹침 보정을 4회 수행한다.
- 기존 2단위 크기의 XZ 격자와 칸별 연결 목록을 사용한다. 검색 범위와 적 반경에 따라 검사할 칸 수를 계산한다.
- 좌우 선호 방향, 속도 보간, 분리 가중치, 적끼리 겹침 보정은 유지한다. 플레이어 접근 제한은 위치 강제 보정 대신 추적 속도를 줄이는 방식이다. 이전 버전의 후보 각도 탐색과 접촉 상태 로직은 사용하지 않는다.
- Collider 기반 물리 충돌이나 복잡한 장애물 경로 탐색은 추가하지 않는다. 극단적인 밀집에서는 잔여 겹침이 남을 수 있다.
- GameScene에 수동 배치된 Bat 오브젝트들로 이동을 검증한다.
- 적 이동과 카메라 외에 지팡이의 조준·투사체 발사만 구현되어 있다. 적 체력·투사체 피해·사망 처리를 구현했다. 넉백·박쥐 무리 생성은 아직 구현하지 않았다.

### 기본 적 스폰 — 현재 구현 규칙

- EnemySpawner 하나가 기존 ObjectPool을 등록하고 Bat 프리팹 한 종류를 생성한다. 시간대별 웨이브나 다른 적 종류는 아직 구현하지 않는다.
- 카메라 추적 이후의 Game 카메라 네 모서리를 적 이동 높이의 평면에 투영한다. 임의의 경계 바깥으로 반경과 여유 거리를 더해 생성한다. 기본 높이는 1, 화면 밖 여유 거리는 2이다.
- 기본 스폰 간격은 1초, 최소 적 수는 15, 최대 적 수는 50이다. Inspector에서 조절한다. 시작 프레임에도 부족한 수를 채운다.
- 활성 EnemyMovement 수를 확인해 최소 수에 부족한 만큼만 생성한다. 최대 수 이상일 때는 생성하지 않으며, 최소 수가 최대 수보다 크면 최대 수로 제한한다. 최대 수를 낮췄다고 기존 적을 제거하지 않는다.
- 기존 씬의 수동 배치 박쥐 3개도 살아 있는 적 수에 포함한다. 이들은 기존처럼 사망 시 Destroy하고, 풀에서 생성한 적만 풀로 반환한다.
- EnemyMovement.SetTarget은 생성된 적에 플레이어 참조를 전달하는 연결 메서드이다. 군중 이동 계산은 유지한다.
- 재활성화 시 EnemyHealth의 체력과 사망 상태를 초기화한다. 피해 계산은 유지하고 풀 소유 적의 사망만 기존 ObjectPool 반환으로 연결한다.
- EnemySpawner의 Enemy Pool 설정에서 프리팹과 준비 수를 지정한다. 기존 풀 종류에 Bat를 추가했으며, 향후 적 종류는 풀 종류와 프리팹을 추가하고 스포너의 생성 규칙을 확장한다. 별도 웨이브 시스템은 미리 만들지 않는다.

## 5. 스테이지 — 확정 기획

| 진행 시간 | 등장 구성 | 의도 |
| --- | --- | --- |
| 0~1분 | 박쥐 | 기본 전투와 조작 적응 |
| 1~2분 | 박쥐, 좀비 | 적 종류 추가 |
| 2~3분 | 박쥐, 좀비, 박쥐 무리 이벤트 | 첫 번째 대량 생성 |
| 3~4분 | 스켈레톤, 박쥐 | 난이도 상승 |
| 4~5분 | 유령, 스켈레톤 | 빠른 적 등장 |
| 5~6분 | 머드맨, 스켈레톤 | 높은 체력의 적 등장 |
| 6~7분 | 머드맨, 좀비 | 적 생성량 증가 |
| 7~8분 | 박쥐, 머드맨, 박쥐 무리 이벤트 | 두 번째 대량 생성 |
| 8~9분 | 좀비, 유령, 머드맨 | 여러 특성의 적 조합 |
| 9~10분 | 박쥐, 좀비, 스켈레톤, 유령, 머드맨, 박쥐 무리 이벤트 | 마지막 혼합 웨이브 |
| 10분 도달 | 스테이지 클리어 | 생존 성공 |

적별 수치, 생성 간격·수량·비율, 이벤트의 정확한 시점과 지속 시간은 추후 결정한다.

## 6. 자동 전투 — 확정 기획

최종적으로 다음 네 가지 공격을 구현한다. 구체적인 수치와 세부 동작은 각 기능 구현 단계에서 결정한다.

| 공격 | 기본 동작 | 참고 무기 |
| --- | --- | --- |
| 마법 지팡이 형태 | 플레이어 주변에서 가장 가까운 적을 향해 투사체 발사 | 마법 지팡이 |
| 채찍 형태 | 플레이어를 기준으로 좌우 방향의 적 공격 | 채찍 |
| 단검 형태 | 플레이어가 바라보는 방향으로 투사체 발사 | 단검 |
| 원형 범위 공격 | 플레이어 주변 일정 범위의 적 공격 | 성경 |

채찍의 좌우 기준과 단검의 방향 결정 방식, 원형 공격의 공전·범위 피해 방식은 아직 확정하지 않았다.

### 마법 지팡이 레벨 1 — 현재 구현 범위

- Player의 MagicWand가 지정된 게임 카메라 화면 안의 활성 EnemyMovement 중 가장 가까운 적을 선택한다. 적 중심의 viewport 좌표와 near/far 범위로 화면 안 여부를 판정한다.
- 기본 쿨타임은 1.2초이며 한 번에 1개를 발사한다. 화면 내 대상이 없으면 발사하지 않고 다음 주기에 다시 탐색한다.
- 발사 순간 적 방향을 저장해 푸른 투사체를 직선 이동시킨다. 발사 후 적을 추적하거나 플레이어를 따라가지 않는다.
- 기본 투사체 속도는 초당 12이며 인스펙터에서 조절한다. 기존 Blue 재질을 사용한 구형 프리팹이다.
- 투사체 중심이 게임 카메라 화면 또는 클리핑 범위를 벗어나면 Destroy한다. Scene 뷰 카메라는 판정에 사용하지 않는다.
- 투사체의 이전 위치부터 다음 위치까지의 선분과 적 중심 사이의 거리를 검사한다. 적 Body Radius와 투사체 Hit Radius(기본 0.125)를 더한 구형 근사 범위에 닿으면 투사체만 Destroy한다. 별도 Collider는 추가하지 않는다.
- 명중 검사는 EnemyCrowd의 격자를 사용한다. 이동 구간의 XZ 경계를 최대 적 반경 + 투사체 반경만큼 확장한 범위의 칸만 순회하고, 후보 적에 기존 3D 선분 거리 검사를 적용한다. 빠른 투사체가 여러 칸을 통과해도 구간 전체를 검사한다.
- 군중의 마지막 겹침 보정 후 최종 위치로 격자를 갱신한다. 등록·해제 직후나 해당 프레임에 아직 갱신되지 않은 경우 첫 명중 조회에서 현재 위치로 갱신한다. 투사체마다 배열이나 후보 목록을 생성하지 않는다.
- 군중 이동 계산과 투사체 직선 이동·명중 시 제거·화면 밖 제거 규칙은 유지한다. 투사체는 군중 이동 이후 LateUpdate에서 처리한다.
- 적의 EnemyHealth에서 Max Health 기본값 5, 투사체 프리팹의 Damage 기본값 10을 인스펙터에서 조절한다. 명중 시 한 적에게 공격력만큼 피해를 주고 투사체를 제거한다.
- 체력은 0 미만으로 내려가지 않는다. 체력 0이면 즉시 비활성화해 조준·군중 목록에서 제외한다. 풀 소유 적은 반환하고 그 외 적은 Destroy한다. 같은 프레임의 중복 사망 처리는 막는다.
- 이동 구간에 여러 적이 있으면 구형 판정 범위의 최초 접촉 시점이 가장 이른 적을 선택한다. 적 이동과 기존 격자 검색은 유지한다.
- 관통, 무기 레벨 강화, 오브젝트 풀링, 경험치 드롭은 아직 구현하지 않는다.
- 향후 기준: 초기 피해량 10, 연사 간격 0.1초. 현재 발사 수가 1개라 연사 간격은 동작에 영향을 주지 않으며 연사는 추후 구현한다.
- 향후 레벨 효과: 2레벨 투사체 +1, 3레벨 쿨타임 -0.2초, 4레벨 투사체 +1, 5레벨 피해량 +10, 6레벨 투사체 +1, 7레벨 관통 +1, 8레벨 피해량 +10. 아직 구현하지 않는다.

## 7. 경험치와 레벨업 — 확정 기획

1. 적을 처치하면 일정 확률로 경험치 보석이 생성된다.
2. 플레이어가 보석을 획득하면 경험치가 증가한다.
3. 일정량의 경험치가 쌓이면 레벨업한다.
4. 레벨업 시 게임을 일시정지하고 선택 UI를 표시한다.
5. 플레이어가 선택지 중 하나를 선택한다.
6. 새 무기 또는 장신구를 획득하거나, 기존 무기 또는 장신구를 강화한다.
7. 선택 효과를 적용하고 게임을 재개한다.

경험치량, 레벨별 필요 경험치, 선택지 개수와 구성 규칙은 추후 결정한다.

## 8. 장신구 — 확정 기획

### 공통 규칙

- 장신구는 총 5종이며 각각 최대 레벨은 5이다.
- 획득 즉시 효과를 적용한다.
- 같은 장신구를 다시 선택하면 레벨이 증가한다.
- 효과는 해당 플레이가 종료될 때까지 유지된다.
- 최대 레벨에 도달한 장신구는 레벨업 선택지에서 제외한다.
- 초기 구현에서는 해금 조건과 무기 진화를 제외한다.
- 아래 수식의 `L`은 해당 장신구 레벨이며, 미보유 상태는 0이다.

### 검은 심장 (Hollow Heart)

- 강화 능력치: 최대 체력
- 레벨당 **현재 최대 체력을 기준으로 20% 누적 증가**한다.
- 최대 체력이 증가해도 현재 체력은 자동으로 회복되지 않는다.
- 다른 최대 체력 효과가 없는 경우: `기본 최대 체력 × 1.2^L`
- 기본 최대 체력이 100이면 레벨 1에서 120, 레벨 5에서 248.832이다.
- 현재 체력이 `70/100`일 때 첫 획득 후에는 `70/120`이 된다.
- 소수점 처리 방식은 구현 전에 확인한다.

### 시금치 (Spinach)

- 강화 능력치: 모든 무기의 공격력
- 레벨당 공격력 보너스 10%, 최대 50%이다.
- 마법 지팡이, 채찍, 단검, 원형 범위 공격에 공통 적용한다.
- 수식: `기준 공격력 × (1 + 0.1 × L)`
- 기준 공격력 10, 레벨 3이면 최종 공격력은 13이다.
- 무기 자체의 레벨 강화와 결합할 때 사용할 기준 공격력은 구현 전에 확인한다.

### 빈 책 (Empty Tome)

- 강화 능력치: 모든 무기의 공격 쿨다운
- 레벨당 쿨다운 감소 8%, 최대 40%이다.
- 수식: `기본 공격 쿨다운 × (1 - 0.08 × L)`
- 기본 공격 주기 1초, 레벨 3이면 최종 공격 주기는 0.76초이다.
- 연속 발사 내부 간격과 원형 공격의 피해 간격까지 적용하는지는 구현 전에 확인한다.

### 날개 (Wings)

- 강화 능력치: 이동 속도
- 레벨당 이동 속도 보너스 10%, 최대 50%이다.
- 수식: `기본 이동 속도 × (1 + 0.1 × L)`
- 기본 이동 속도 5, 레벨 3이면 최종 이동 속도는 6.5이다.

### 매혹의 오브 (Attractorb)

- 강화 능력치: 경험치 보석 획득 범위
- 레벨당 획득 범위 보너스 20%, 최대 100%이다.
- 수식: `기본 획득 범위 × (1 + 0.2 × L)`
- 기본 획득 범위 2, 레벨 3이면 최종 획득 범위는 3.2이다.
- 획득 범위의 거리 판정과 보석의 즉시 획득·끌어당김 방식은 구현 전에 확인한다.

검은 심장은 누적 곱셈이고, 나머지 네 장신구의 레벨 보너스는 기본값 기준 합산이다.

## 9. 권장 개발 순서 — 미확정 제안

짧은 플레이에서도 핵심 순환이 연결되도록 만든 후 콘텐츠를 늘리는 순서이다. 이 순서 자체가 전체 구현 요청은 아니다.

| 단계 | 범위 | 완료 기준 |
| --- | --- | --- |
| 1 | 플레이어 이동, 바라보는 방향, 카메라, 임시 바닥 | WASD·방향키로 이동하며 전투 공간 확인 |
| 2 | 적 1종 생성·추적, 플레이어 체력, 접촉 피해, 패배 | 화면 밖 생성과 추적, 체력 0에서 종료 |
| 3 | 마법 지팡이, 적 체력·사망 | 가장 가까운 적을 자동 공격하고 처치 |
| 4 | 경험치 보석, 레벨업, 선택 UI, 지팡이 강화 | 처치 → 경험치 → 선택 → 전투 재개 연결 |
| 5 | 채찍, 단검, 원형 범위 공격 | 새 무기 획득과 여러 무기의 동시 동작 |
| 6 | 장신구 5종, 레벨 제한, 선택지 제외 | 획득 즉시 능력치 반영 |
| 7 | 적 5종, 시간대별 생성, 박쥐 무리, 승리 | 지정한 구성으로 10분 진행 후 클리어 |
| 8 | HUD, 재시작, 난이도·성장 속도 조정 | 실제 10분 플레이와 결과 확인 |

4단계까지 완성한 시점에 핵심 재미와 성장 속도를 검토하고, 이후 무기와 적 종류를 추가하는 것을 권장한다.

## 10. 추가 결정 사항

모든 항목을 지금 확정할 필요는 없다. 해당 기능을 구현하기 전에 필요한 항목부터 확인한다.

### 10.1 이동과 카메라 — 첫 구현 전

- 스테이지 경계와 이동 가능 범위, 장애물 유무

**확정:** XZ 평면의 월드 기준 이동과 Y 좌표 유지, 직교 Z축 기준 쿼터뷰와 고정 각도·즉시 추적. **미확정 권장안:** 장애물 없는 바닥. 기존 화면 기준 이동 제안은 월드 기준 이동 결정으로 대체한다.

### 10.2 전투와 피격 — 해당 기능 구현 전

- 단검 방향: 마지막 이동 방향 또는 마우스 등 별도 방향 지정
- 채찍 좌우: 화면 기준 또는 플레이어 방향 기준
- 원형 공격: 공전 물체의 접촉 피해 또는 주기적 범위 피해
- 무기별 피해량, 사거리, 공격 주기, 투사체 수·속도·관통, 강화 내용
- 시작 무기와 무기별 최대 레벨
- 적 접촉 피해량과 피해 간격
- 피격 후 무적 시간 및 여러 적의 피해 중첩 방식
- 플레이어와 적, 적끼리의 충돌·밀어내기 방식

### 10.3 성장과 선택 UI — 해당 기능 구현 전

- 경험치 보석 드롭 확률과 경험치량
- 레벨별 필요 경험치
- 레벨업 선택지 개수와 중복 방지 규칙
- 새 무기, 무기 강화, 장신구를 같은 선택지에 섞을지
- 무기·장신구의 보유 개수 제한: 전부 보유 가능 또는 일부만 선택
- 모든 항목이 최대 레벨일 때의 처리
- 경험치를 한 번에 많이 얻어 여러 번 레벨업할 때의 처리

### 10.4 장신구 적용 — 임의 결정 금지

- 검은 심장의 소수점 유지·반올림 규칙
- 무기 레벨 강화와 시금치 배율의 적용 순서와 기준값
- 빈 책이 줄이는 시간의 범위: 공격 주기, 연속 발사 간격, 원형 공격 피해 간격
- 매혹의 오브의 범위 판정 기준과 즉시 획득·끌어당김 동작

### 10.5 스테이지와 결과 — 해당 기능 구현 전

- 적별 체력·이동 속도·접촉 피해량
- 시간대별 생성 간격·수량·종류별 비율
- 화면 밖 생성 위치를 판단하는 기준
- 박쥐 무리의 정확한 발생 시점·지속 시간·추가 생성량
- 시간대가 바뀌어도 기존 적을 유지할지
- 레벨업 일시정지 중 생존 타이머도 정지할지
- 10분 도달과 사망이 동시에 발생할 때 결과 우선순위

**권장안:** 레벨업 선택 시간을 제외한 실제 전투 시간을 생존 시간으로 계산한다. 아직 확정하지 않았다.
